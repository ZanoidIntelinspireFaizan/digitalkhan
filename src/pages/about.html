About

Software Developer & Product Builder.

I build software because I keep running into the same problem: most tools and starter setups are either too heavy for the job or too thin to ship with. I'd rather make the thing once, properly, and reuse it.

Digital Khan is where I publish that work — small products, technical writing, and the occasional project. Everything here is mine: the code, the copy, the mistakes, and the maintainership.

01 How I Work

Practical software

Working software beats impressive architecture. If a feature doesn't move a real problem forward, it doesn't ship.

Real problems

I build for the day-to-day work I actually do — installing, deploying, administering, maintaining. Not for a hypothetical enterprise.

Reusable systems

The most valuable code is the kind you can use on the next project. That's why I productize the foundation once and reuse it everywhere.
